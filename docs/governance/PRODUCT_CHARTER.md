# Research portfolio charter

Present `3D-Craniofacial-Pipeline` through a concise English README, workflow diagram, selected saved
results, and original analysis code. The owner approved this scope and GitHub publication
on 2026-09-28, explicitly excluding analysis reruns. Clinical validation and new
statistical analysis are outside this release. Owner: [trungnb](https://github.com/trungnb).

The owner clarified that this is a prototype of a 3D-to-2D projection proposal for
forensic AM–PM comparison. The public presentation emphasizes storage footprint,
comparison time and overlap. The prototype inputs are two CBCT scans; the proposed
head CT study and its larger-scale simulations remain planned work.
